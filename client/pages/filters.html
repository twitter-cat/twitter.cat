filter guide

twitter.cat uses a basic filter syntax to help you search through tweets and accounts. this guide will show you how to use filters to find exactly what you're looking for.

basic syntax

filters use simple comparison operators:

  • = equals
  • != not equals
  • > greater than
  • >= greater than or equal
  • < less than
  • <= less than or equal

you can combine conditions using:

  • AND both conditions must be true
  • OR either condition can be true
  • NOT negates a condition
  • ( ) parentheses to group conditions

important: text values must be wrapped in quotes like "example"

1. filtering accounts

when filtering user accounts, you can use these fields:

  • id - user's numeric id
  • username - handle without @
  • name - display name
  • bio - profile description
  • location - user's location
  • verified - verification status (true/false)
  • protected - account privacy (true/false)
  • followers - follower count
  • following - following count
  • fast_followers - fast follower count
  • likes - total likes given
  • media_count - media uploads
  • listed_count - times listed
  • tweets - total tweet count
  • created_at - account creation date (unix timestamp)
  • added_at - when added to database (unix timestamp)
  • professional_type - professional account type
  • professional_category - professional category

account filter examples

find verified accounts with over 100k followers:

verified = true AND followers > 100000

find accounts from a specific location:

location = "New York"

find active accounts (high tweet count, recent):

tweets > 1000 AND followers > 5000

find accounts with specific words in bio:

bio = "developer" OR bio = "engineer"

find popular non-verified accounts:

verified = false AND followers > 50000

find accounts by follower to following ratio:

followers > 10000 AND following < 1000

find protected accounts with high engagement:

protected = true AND (followers > 1000 OR tweets > 5000)

find professional accounts:

professional_type = "business"

2. filtering tweets

when filtering tweets, you can use these fields:

  • id - tweet's numeric id
  • author_id - id of the tweet author
  • body - tweet text content
  • created_at - when tweet was posted (unix timestamp)
  • like_count - number of likes
  • reply_count - number of replies
  • retweet_count - number of retweets
  • quote_count - number of quote tweets
  • views_count - view count
  • bookmarks_count - bookmark count
  • lang - language code (e.g., "en", "es")
  • source - posting platform
  • reply_to_status_id - id of tweet being replied to
  • reply_to_user_id - id of user being replied to
  • conversation_id - thread conversation id
  • quoting_id - id of quoted tweet
  • added_at - when added to database (unix timestamp)
  • has_poll - contains a poll (true/false)
  • has_embed - has embedded content (true/false)
  • has_media - has media attachments (true/false)

tweet filter examples

find viral tweets (high engagement):

like_count > 10000 AND retweet_count > 1000

find tweets from a specific user:

author_id = "1774176655176556544"

find popular tweets with media:

has_media = true AND like_count > 5000

find tweets in english with high views:

lang = "en" AND views_count > 100000

find tweets that are replies:

reply_to_status_id EXISTS

find original tweets (not replies or quotes):

reply_to_status_id NOT EXISTS AND quoting_id NOT EXISTS

find tweets with polls:

has_poll = true

find recent viral content:

created_at > 1700000000 AND (like_count > 1000 OR retweet_count > 500)

find highly bookmarked tweets:

bookmarks_count > 1000

find tweets from mobile vs web:

source = "Twitter for iPhone"

find tweets in a specific conversation:

conversation_id = "1234567890123456789"

advanced filtering

combine multiple conditions with AND:

author_id = "12345" AND like_count > 100 AND has_media = true

use OR for alternatives:

lang = "en" OR lang = "es" OR lang = "fr"

use NOT to exclude:

like_count > 1000 AND NOT has_media = true

group conditions with parentheses:

author_id = "12345" AND (like_count > 1000 OR retweet_count > 500)

complex viral content filter:

(like_count > 10000 OR retweet_count > 5000) AND lang = "en" AND has_media = true AND NOT reply_to_status_id EXISTS

find tweets from multiple specific users:

(author_id = "12345" OR author_id = "67890") AND like_count > 100

working with timestamps

timestamps use unix format (seconds since january 1, 1970). some helpful conversions:

  • december 1, 2024 = 1733011200
  • january 1, 2024 = 1704067200
  • january 1, 2023 = 1672531200

find tweets from the last month:

created_at > 1733011200

find tweets in a date range:

created_at > 1704067200 AND created_at < 1733011200

tips

  • use parentheses when combining AND and OR to avoid confusion
  • remember that AND takes precedence over OR without parentheses
  • always wrap text values in quotes: "example"
  • use EXISTS to check if a field has any value
  • use NOT EXISTS to check if a field is empty
  • boolean fields like verified, has_media use true or false (no quotes)

experiment with different combinations to find exactly what you need!
